# 📝 Mini Notes - Flask

A simple notes web application built while learning **Flask** and Python backend development.

## 🎯 Project Goal

The goal of this project is to learn the fundamentals of Flask by building a small full-stack web application.

Users will be able to:

- Write a note
- Submit the note
- View saved notes
- Edit notes
- Delete notes

## 🛠️ Technologies

- Python
- Flask
- HTML
- CSS
- Jinja2
- SQLite

## 📚 What I Will Learn

- Creating a Flask application
- Flask routes
- HTTP GET and POST requests
- HTML forms
- Handling user input
- Jinja2 templates
- Static files
- SQLite databases
- CRUD operations
- Basic project structure
- Flask application deployment
